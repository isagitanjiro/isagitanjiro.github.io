# Screenshots

Drop your ZenChain screenshots here. The website will show them automatically.

## How to add your screenshots

1. Put your image files in this folder using **these exact names**:

   - `community.png` — Community screenshot
   - `event.png` — Event screenshot
   - `campaign.png` — Campaign screenshot

2. Save the files. The dev server refreshes automatically and your images appear in the Selected Work section.

## Supported formats

`.png`, `.jpg`, `.jpeg`, `.webp`, `.avif` — all work. Just keep the base name the same (e.g. `community.jpg` or `community.webp`).

## Until you add files

The elegant placeholder ("Community Screenshot", etc.) keeps showing. No broken images.
